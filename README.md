# 귀염뽀쨕도트 런처 배포 파일

[귀염뽀쨕도트 런처](https://github.com/AliceGameLand/Dot-Launcher)의 게임 파일과 기본 설정을 관리합니다.

Node.js 22에서 `npm run prepare`로 릴리스 파일을 준비하고 `npm run verify`로 검증합니다.
게시 후에는 `npm run verify:remote`로 공개 다운로드와 해시를 확인합니다.

각 모드·셰이더의 권리는 해당 제작자에게 있습니다. 파일 버전과 해시는 `distribution.json`, `artifacts.json`에 기록합니다.
